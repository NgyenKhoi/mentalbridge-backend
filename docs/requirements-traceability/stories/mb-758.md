# MB-758 traceability

[Requirements traceability index](../../requirements-traceability.md)

[MB-758](https://vunguyenkhoi47.atlassian.net/browse/MB-758), Journal/AI owner,
adds the guarded internal Voice turn API after merged MB-757 #232. It implements
the frozen [MB-755 contract](../../../contracts/proposals/companion-voice-v1.openapi.json)
under [ADR 0046](../../adr/0046-ai-voice-companion-contract.md) and
[Voice policy v1](../../policies/companion-voice-policy-v1.md).

[Active OpenAPI v1.15.0](../../../contracts/openapi/journal-ai-service-v1.yaml)
defines final vi-VN input, current attempt/lease, ordered turn/retry identity,
closed reply and safe errors. Worker authentication remains separate from USER
JWTs. Journal derives the owner, checks both Care grants/current entitlement and
admitted usage before generation/publication, and reuses the existing approved
Companion Claude Bedrock route, prompt and normalized safety validator. No Text
`send`, stored context assembler or Text-quota repository is called.

[Migration 015](../../../journal-ai-service/migrations/015_companion_voice_turn_fences.cjs)
extends the existing media-command aggregate with content-free generation
fences. [Mongo documentation](../../database/mongodb.md#mb-758-voice-generation-fences)
and the [canonical document model](../../domain-model/document/mongodb-logical-model.md#ai-companion-voice-media-command--active)
describe the compatible validator, unique partial indexes, RAM-context fence and
original retention cap. There is no new collection/entity owner or transcript
storage. Missing RAM cannot regenerate accepted work. Shutdown/end/failure/
expiry/revocation cancels processing and discards current-call content.

[Acceptance and execution evidence](../../story-mb-758-guarded-voice-turns.md)
maps real Nest + Mongo concurrent generation, five Vietnamese turns, safe output,
replay/reconnect, cancellation/late results, owner withdrawal, expiry and unchanged
Text quota. [Operator handoff](../../ai-voice-demo-runbook.md#mb-758-turn-checkpoint)
requires context-process affinity and retains downstream account/privacy, hosted
worker, speech and real-device gates. No Cloud deployment, paid inference or
live speech success is claimed. Consultation/SupportPlan behavior is unchanged.
