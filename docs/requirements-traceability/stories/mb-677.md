## Delivery contract 2026-10-24

MB-677 extends Content/Notification native delivery with a bounded appointment
reminder route based on Consultation's versioned status event and exact current
owner check. Cancellation, reschedule, quiet hours, replay, multi-device fanout
and privacy rules are fixed in the
[acceptance record](../../story-mb-677-reminder-push-routing.md).

SupportPlan activity push remains deferred because the current Care occurrence
event does not publish the approved reminder instant, timezone or reminder
choice. This delivery does not poll Care storage or private owner projections
to invent those facts.
