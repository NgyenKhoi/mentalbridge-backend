# MB-806 — two AI consent levels

Recorded: 2026-11-06. Owner decision: [ADR 0050 / MB-TWO-LEVEL-AI-CONSENT-001](../../adr/0050-two-level-ai-consent.md).

## Backend delivery boundary

Care keeps immutable current `AI_PROCESSING` v2 and existing grants as L1 only,
adds independent dependent `AI_CONTEXT_PROCESSING` v1 without backfill, and
publishes the L2 notice plus atomic effective snapshot. Decisions remain
append-only, profile-locked, monotonically ordered and idempotently replayable.
L1 withdrawal suspends current true L2; regrant restores it without selecting
sources. Privacy and separate Voice v2 remain independent.

Journal/AI checks L1 chat/Voice and L2 personal sources, exact/longitudinal
analysis, Care projections, plan companion, saved-brief draft, Guide phrasing
and emotion projection at request/source access and each provider attempt.
Personal-kind memory is filtered before decryption, provenance stays truthful,
new conversations select no sources and deterministic fallbacks remain available.
No paid provider call, frontend delivery, shared database operation or Docker
rebuild is part of this implementation job.

## Contracts and consumers

Care 1.11.0 and Journal/AI 1.18.0 OpenAPI are canonical. ngocquyen owns frontend
MB-805/807 and runs `npm run contracts:sync` after backend merge. The contract-ready
manifest and final backend handoff live in the local story artifacts; the handoff
records exact gate counts and any external blocker without inferring completion.

## Acceptance evidence

Care tests cover independent decisions, effective dependency/regrant, immutable
notice/history, replay-before-policy/dependency, ownership, frozen/backward-clock
ordering, migration upgrade and real-PostgreSQL concurrency. Journal tests cover
request/source/attempt checks, malformed or unavailable Care, retry/reclaim without
persisted bearer, whole synthetic provider payloads, personal-memory taint and
Voice empty-kind limits. Required module and repository gates are recorded at
handoff; real-provider and frontend verification remain outside scope.
