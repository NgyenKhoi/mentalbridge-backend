# MB-757 traceability

[Requirements traceability index](../../requirements-traceability.md)

[MB-757](https://vunguyenkhoi47.atlassian.net/browse/MB-757) delivers the
Journal/AI LiveKit session control plane following merged MB-756 #231 and the
frozen [MB-755 contract](../../../contracts/proposals/companion-voice-v1.openapi.json),
[ADR 0046](../../adr/0046-ai-voice-companion-contract.md) and
[Voice policy v1](../../policies/companion-voice-policy-v1.md).

The [active contract](../../../contracts/openapi/journal-ai-service-v1.yaml)
publishes four USER session routes and two dedicated worker lifecycle routes.
Current Care dual consent and Consultation entitlement authorize admission and
fresh joins; the existing atomic ledger remains the sole quota/capacity authority.
Explicit named dispatch uses opaque AI-only references, restricted short-lived
microphone grants and independent provider teardown confirmation. Unknown SDK
outcomes retain the capacity permit and reconcile the original side effect.

[Migration 014](../../../journal-ai-service/migrations/014_companion_voice_media.cjs),
the [Mongo dictionary](../../database/mongodb.md#ai-companion-voice-admission-and-usage-collections)
and [canonical document model](../../domain-model/document/mongodb-logical-model.md#ai-companion-voice-media--active)
cover bounded room/dispatch progress, sequence fencing and keyed command binding.
Metadata expires in the original session's 30-day window; no media credential,
audio, transcript, model text or prior history is stored. Deletion never frees
uncertain media capacity or clears anonymous quarantine.

[Implementation and acceptance evidence](../../story-mb-757-livekit-sessions.md)
maps deterministic official-SDK transport tests, actual Nest REST boundary tests
and real MongoDB concurrency/crash/cleanup checks. The
[runbook](../../ai-voice-demo-runbook.md#mb-757-control-plane-checkpoint) keeps
enablement opt-in after downstream/account/privacy verification. MB-758 inference
turns, MB-759 hosted worker, MB-760 speech and MB-762 real-device E2E remain outside
this story. Existing Consultation rooms, attendance, credits and text quota are
unchanged. This checkpoint does not claim a deployed or working live voice call.
